# 06 — Angular UI

Angular 22 (the framework workspace is on `@angular/core` 22.2), standalone
components, signals, zoneless, lazy routes. Lives in `gamematcher/ui/` as its
own workspace and consumes `miniframework-ng` (schema-driven decoders, the
instrumented fetch client) from `../../miniframework/web/projects/miniframework-ng`.
Sprint 0 decides between a TS path mapping and a `file:` dependency, whichever builds
cleanly from Git Bash with `make`.

### The plan screen

The core interaction. On a phone it's one column:

```
 Game night                     open · hosted by Dad
 ─────────────────────────────────────────────────
 Are you in?   [ In ] [ Maybe ] [ Out ]

 When can you do?
   Sat 2–6pm        [Yes] [If needed] [No]    ●●● Mom, Sam, Dad  ○ Alex
   Sun 1pm          [Yes] [If needed] [No]    ●   Dad

 What would you play?   (tick all)
   [x] Catan            Mom, Dad, Sam      3–4
   [ ] Factorio         Alex               1–∞
   [x] Wingspan         Dad                1–5
   ░ Twilight Imperium  —        needs 3+, 4–8h

 Note: [ only after 3                  ]        [ Save ]
 ─────────────────────────────────────────────────
 Comments (4)
```

- Saving is one `PUT …/response`. Optimistic, rolled back on 409 with a
  "the plan changed, here it is now" message.
- The host sees **Lock in** (pick a time, optionally games). Nothing is
  pre-selected for them, by owner decision 9.

## Behaviour requirements

- Mobile first and usable one-handed. Desktop gets two columns, nothing more.
- Works on HTTP and HTTPS identically. Never redirects between them.
- **Polling:** only `GET /api/v1/me/summary`, every ≥ 60 s while
  `document.visibilityState === 'visible'`, plus on focus. Every other fetch
  is user-driven. One open tab costs at most one request per minute.
- Connection status chip from the framework client: shows "board not
  responding" after 2 failed polls instead of failing silently.
- Accessible: real `<button>`/`<label>`, keyboard reachable, visible focus,
  and the response grid works as a radio group for screen readers. Colour is never the
  only signal (dots have counts and names).
- Dates: `Intl.DateTimeFormat` in the browser's zone. Relative words
  ("tonight", "tomorrow").
- No external fonts, icons or CDNs. It must work with the internet unplugged.

## Bundle budget

| | Budget (gzip) |
|---|---|
| Initial (shell + home + sign-in) | **120 KB** |
| Any lazy route | 40 KB |
| Admin chunk | 60 KB |
| Total bundled into firmware | 300 KB |

Enforced with `angular.json` budgets (`error`, not `warning`). Housemetrics'
whole dist is about 390 KB raw. The framework gzips at build time and serves hashed
names `immutable`, so a returning phone loads only `index.html` and the API.
