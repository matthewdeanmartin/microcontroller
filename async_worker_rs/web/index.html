Eight job slots. One worker. Five seconds between upstream calls. Results remain for two minutes.

What this experiment demonstrates

The HTTP handler admits a job and returns immediately. A separate Rust thread / FreeRTOS task performs the UDP exchange. Polling reads a small snapshot; it never waits for NIST. There is no browser-to-NIST request.

“Async” describes the request/job contract. This implementation uses a bounded worker thread, not Rust async/await. Jobs live in RAM and disappear after a restart. NTP samples are unauthenticated server transmit timestamps, not precision clock synchronization.
